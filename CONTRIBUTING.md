# Contributing to FGLabs projects

Start with the repository's README, contribution guide, and roadmap. Project-specific instructions take precedence over this general guide.

For bugs, include the application version, operating system, steps to reproduce, and expected and observed behavior. Remove credentials and personal information from logs and screenshots.

For substantial features or design changes, open an issue first so the scope can be discussed before implementation.

Keep pull requests focused, explain the behavior they change, and include the relevant validation results. Follow the repository's existing conventions and license.

Do not report security vulnerabilities in public issues. Follow the affected repository's security policy.
