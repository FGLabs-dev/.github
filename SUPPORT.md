# Getting help

For reproducible bugs and feature requests, use the affected project's issue tracker. Check existing issues and the README first.

Include the product version, operating system, steps to reproduce, and expected and observed behavior. Share the smallest useful log excerpt after removing credentials, tokens, personal paths, and private data.

For questions involving private information, installation help, or product support, write to [support@fglabs.dev](mailto:support@fglabs.dev) or use the [website contact form](https://fglabs.dev/contact).

For general inquiries, use [inquiries@fglabs.dev](mailto:inquiries@fglabs.dev). For contributor proposals, integrations, or partnerships, use [collaboration@fglabs.dev](mailto:collaboration@fglabs.dev).

Security vulnerabilities should be reported privately following the repository's SECURITY.md. When it has no project-specific policy, use the [FGLabs security policy](https://github.com/FGLabs-dev/.github/blob/main/SECURITY.md).

Project-specific support instructions take precedence over this general guide.
